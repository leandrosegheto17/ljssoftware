Smoke-test — base.css

Instruções de validação manual (T1.3): abra este arquivo no navegador, abra o DevTools (F12) → modo responsivo → teste as larguras 360px, 768px e 1024px. Em nenhuma delas deve aparecer barra de rolagem horizontal, e o grid abaixo deve mostrar 1 / 2 / 3 colunas respectivamente.

.container

Este bloco de texto está dentro de .container: deve ter respiro lateral (padding) e ficar centralizado com largura máxima de 1200px em telas grandes, sem nunca causar rolagem horizontal em 360px.
